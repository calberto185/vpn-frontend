Guía rápida para conectarte a la VPN

Sigue estos pasos: crea tu cuenta, elige un plan, agrega dispositivos, descarga tus credenciales .ovpn, impórtalas y conéctate.

Ir al portal Descargas Contactar soporte

1) Crea tu cuenta

  1. Visita {{ portalUrl }} y pulsa Crear cuenta.
  2. Ingresa tus datos: nombres, apellidos, correo y una contraseña segura.
  3. Revisa tu bandeja y haz clic en el enlace de verificación.
  4. Inicia sesión con tu correo y contraseña.

Tip: usa una contraseña con 12+ caracteres y activa 2FA si está disponible.

2) Elige tu plan

  1. En el panel, abre Planes.
  2. Compara límite de dispositivos, ancho de banda y precio.
  3. Pulsa Suscribirme y completa el pago (si aplica).

Podrás cambiar de plan más adelante sin perder tus dispositivos.

3) Agrega tus dispositivos

  1. Entra a Dispositivos → Agregar dispositivo.
  2. Asigna un nombre (ej.: Mac oficina, Android personal).
  3. Guarda. El portal generará las credenciales para ese dispositivo.

Cada dispositivo tiene su archivo .ovpn único. No lo compartas.

4) Descarga las credenciales .ovpn

  1. En Dispositivos, ubica el equipo y pulsa Descargar .ovpn.
  2. Guarda el archivo en un lugar seguro.
  3. (Opcional) Protege el archivo con contraseña del sistema o bóveda.

Si tu plan lo permite, también podrás descargar un paquete ZIP con certificados y el .ovpn.

5) Importa el archivo .ovpn

  1. Descarga OpenVPN Connect desde Microsoft Store o Descargas.
  2. Ábrelo y pulsa Import Profile → File.
  3. Selecciona tu archivo .ovpn y confirma.
  4. Guarda el perfil y verifica que aparezca en la lista.
  1. Instala OpenVPN Connect para macOS.
  2. Abre la app y arrastra tu archivo .ovpn o ve a Import Profile.
  3. Confirma y revisa que el perfil quede guardado.
  1. Instala OpenVPN Connect desde Google Play.
  2. Envía el archivo .ovpn a tu teléfono (Drive, correo o USB).
  3. En la app, pulsa OVPN Profile y elige el archivo.
  4. Asigna un nombre al perfil y guarda.
  1. Instala OpenVPN Connect desde App Store.
  2. Envíate el .ovpn por correo o Archivos (iCloud/Drive).
  3. Toca el archivo y elige Copiar a OpenVPN.
  4. Importa y guarda el perfil.
  1. Instala OpenVPN: sudo apt install openvpn (Debian/Ubuntu) o usa tu gestor de paquetes.
  2. Conecta por terminal: sudo openvpn --config ./perfil.ovpn.
  3. O usa tu administrador de redes (NetworkManager) para importar el .ovpn.

6) Conéctate

  1. Abre tu app de OpenVPN y selecciona el perfil importado.
  2. Pulsa Connect. Acepta la solicitud de VPN del sistema.
  3. Espera a ver el estado Connected.

Para desconectarte, vuelve a la app y pulsa Disconnect.

Verifica y soluciona problemas

Comprobar conexión

  • Abre Mi IP en el navegador: debería cambiar a la IP de {{ companyName }}.
  • Accede a un recurso interno (intranet, Git, base de datos) que requiera VPN.
  • Haz ping a una IP interna autorizada.

Si algo falla

  • Perfil inválido: descarga otra vez el .ovpn desde Descargas.
  • Credenciales revocadas: borra el perfil y genera uno nuevo en Dispositivos.
  • Restricción de firewall: prueba otra red o habilita puertos/UDP 1194 (o el que use tu servidor).
  • DNS interno: tras conectar, reinicia el navegador o vacía caché DNS.
